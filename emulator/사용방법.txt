게임 플레이: HD_게임실행.cmd 실행
시험 음성은 제거했으며 한글판 1.0.8 기준으로 실행합니다. HD 그림은 유지됩니다.
설정 → 전투 진동 설정…에서 진동 사용·강도·테스트를 선택할 수 있습니다.
진동을 지원하는 게임패드를 연결하고, 키보드·패드 설정의 게임 패드 사용을 켜주세요.
첫 충격과 연속 피격 점멸에 맞춰 짧게 진동하며, HD나 음량을 꺼도 적용됩니다.
일시정지·다른 창으로 이동·게임 종료 때 진동은 멈춥니다.
현재는 피격 점멸 연동이며 필살기·격추별 전용 진동은 포함하지 않습니다.
기존 시험 롬 release_battle_v02/SRWW_K_Kazuma_BattleVoice_v02.nds를 읽습니다.
롬 파일을 추가로 만들거나 수정하지 않습니다.

파일 메뉴에서 .nds 롬이나 최근 게임을 열 수 있습니다.
게임 메뉴에서 저장 칸 1~5를 선택한 뒤 저장·불러오기 버튼을 사용합니다.
중간 저장 파일 가져오기·내보내기와 스크린샷 저장은 파일 메뉴에 있습니다.
도구 모음의 화면 구성 버튼으로 네 가지 배치를 바로 선택할 수 있습니다.
메인 크게·가로 / 메인 크게·세로 / 같은 크기·가로 / 같은 크기·세로
두 게임 화면은 중간 여백이나 테두리 없이 맞닿아 표시됩니다.
메인 크게 배치는 두 화면의 크기 비율이 3:1이며, 모든 화면의 4:3 비율은 유지합니다.
Ctrl+1~4로도 같은 배치를 선택합니다. 화면 메뉴에는 위 화면만 표시도 있습니다.
게임 화면을 더블클릭하면 전체 화면으로 전환하고, 다시 더블클릭하면 창 모드로 돌아옵니다.
전체 화면에서는 메뉴와 도구 모음이 숨겨집니다. Esc나 F11로도 돌아올 수 있습니다.
설정 → 키보드·패드 설정에서 버튼을 누르고 원하는 키나 패드 버튼을 입력한 뒤 적용합니다.
패드 방향은 방향 패드와 왼쪽 스틱을 사용합니다.
설정과 최근 게임은 player_settings.json에 저장됩니다.

HD 위 화면은 고해상도로 합성한 뒤 창 크기에 맞춰 표시합니다.
아래 화면은 배치에 따라 이동하며 마우스로 터치할 수 있습니다.
고해상도 교체 대상은 카즈마 컷인과 ROM에서 추출·등록한 전체 기본 기체 형태 및 추가 무장·변형 파츠입니다.
이제 기체 통짜 그림을 쓰지 않고, 실제 게임 파츠의 위치·반전·회전·겹침 순서로 조립합니다.
위쪽 화면을 담당하는 엔진이 바뀌는 결과 화면도 적용합니다.
파츠 연결부에 원본 접점을 기준으로 한 자동 정렬·투명 영역 보정을 적용했습니다.
등록된 파츠의 보정은 미리 저장해 사용합니다. 파츠 그림 자체의 추가 정리는 계속 필요합니다.
손·무기 조각 17개와 관측한 색상 변형을 추가했습니다. 암전 시 HD 파츠도 함께 어두워집니다.
총기를 세우는 동작의 본체 2개와 회전 잔상 1개도 HD로 연결했습니다.
발호크의 추가 자세와 우주해적 기체의 팔·장갑·무장·변형 조각도 파츠별로 교체합니다.
기존 창에서 새 HD 자료를 읽으려면 게임을 다시 열거나 Ctrl+D로 미리보기를 다시 시작합니다.
등록되지 않은 동작과 기체는 원본으로 표시합니다. 컷인은 기체보다 위에 표시합니다.
기체별 원본/HD 비교는 ../graphics/all_units/index.html을 열면 볼 수 있습니다.
269개 기본 형태와 추가 기계 파츠 자료를 등록했으며, 모든 무기의 실제 전투 재생을 확인한 것은 아닙니다.
피격·암전 등으로 팔레트가 바뀌어도 원래 파츠 무늬를 식별하고 해당 프레임의 색상으로 표시합니다.
HD 그림은 필요한 묶음만 읽으며, 게임을 다시 열면 새 자료가 적용됩니다.
초상화 548개 리소스, 가우롱 컷인 2개와 관측한 전투 배경 6개를 HD로 연결했습니다.
메뉴 글자는 원본 확대이며 전체 게임의 모든 연출 검증은 아직 완료하지 않았습니다.
