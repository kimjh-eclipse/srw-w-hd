# 22591 효과10개 교체 후보

원본의 8연결 성분45개를 각각 참조 패널로 분리해 자체 새 RGBA로 제작했습니다. 각 성분의 위치·사각 크기를 다시 원래 아틀라스에 등록했습니다. 원본RGB/alpha를 출력에 전사하지 않았으며 알파 문턱 삭제·침식/팽창은 없습니다. alpha128은 생성 성분의 등록 bbox를 찾는 기준일 뿐 출력 알파를 이진화하지 않습니다. 원본 1texel짜리 점은 4배에서4×4 범위에 자기 생성 점을 배치합니다. 흰 중심·색 면적/작은 점의 둥근 모서리·연속 줄기/잎 성분은 실제 재생 및 Claude 수치 검사 대기입니다. 기존 92644는 바꾸지 않으며 나머지10개만 같은ID 교체 예정입니다. 매끈한 성분과 원본 성분의 정확한 도트 윤곽은 동일하지 않습니다.
