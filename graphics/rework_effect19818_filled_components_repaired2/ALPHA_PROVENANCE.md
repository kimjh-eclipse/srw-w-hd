# 자체생성 RGBA 근거

두원천모두builtin image_gen을사용했습니다. API/CLI없음. generation_sources.json과sha256.json에원천/SHA를보존했습니다.

92872는원래13×1이모두불투명인직사각재질입니다. 새자체생성불투명분홍~흰색재질전체를52×4로resize해원래x3,y7에놓았습니다. 원본RGB/알파를전사하지않고이미지생성도구로새재질을생성했습니다. 최종팔레트색을원본에서픽셀별주입하는처리없음.

92881은실제투명배경을요청한새생성RGBA전체를target128×128로resize했습니다. 생성알파문턱삭제/형태학연산/원본mask차용없음. 원본의긴흰줄기와바닥평평한가로strip/흰면적/위치폭을요청했고,source계단대신새곡선을그렸습니다.

92855/92861은정상부모와같은source/fullpal/아틀라스자체RGBA이므로생성하지않고보존했습니다. prepare결과의차이는기술보류에기록했습니다. 그림교체로기술차이를숨기지않았습니다. 공식QA/게임검증은미실시입니다.
