## 범위와 보존

- 기존93810~93818의 같은 ID9개 교체 후보입니다. 신규 연결은0개입니다.
- 정상93819~93822 네 개는 설치 계약에서 제외하고 기존 자체 그림·메타 해시를 `normal_four_preserved.json`에 보존했습니다.
- 문제9개는 정상4개의 원본 사각형과 겹치지 않습니다. 문제9개끼리는 부분 겹침·포함 관계가 있어 하나의 원본 성분 그림을 공유하도록 만들었습니다.

## 실제 원본과 제작

- 실제 자료는 `test_current/parts/next_confirmed_fx_source/art_22198/source_contract.json`입니다. 실제 해시·인덱스·전체16색으로 각 ID를 대조했습니다. 최종 계약의 `spec.source_x/source_y`와 `atlas_box`는 서로 다른 용도이며 섞지 않았습니다.
- 문제 영역은 원본 아틀라스 우상단 [96,0,96,32]입니다. 바깥의 청록 숨은 RGB나 격자 형태를 새로운 배경으로 그리지 않았습니다.
- 실제 불투명 원본은 큰 흰/노란 섬광1개와 작은 흰/노란 빛 조각23개입니다. 원본 참조용 성분 목록은 `source_component_geometry.json`에 있으며, 후보는 각 성분마다 생성한 그림 자체 알파를 해당 원본 성분 상자에 맞춰 한 번 배치했습니다. 이후 원래9개 사각형으로 나누므로 겹치는 지원 영역의 그림이 같습니다.
- 원본 RGB·알파를 후보에 찍지 않았습니다. 생성 알파에 강한 문턱 처리를 적용하지 않았고 경계 상자를 찾는 용도로만8을 사용했습니다. 실제 생성 알파는 유지했습니다.
- 설치 입력 `install_contract.json`, `native_atlas.png`(192×32), `candidate_atlas.png`(정확한4배768×128), 생성 원천 `generated_selected.png`, 과정 `provenance.json`입니다.
- `source_input_check.json`에서 최종9개 원본 사각형의 불투명 RGB/알파가 계약의 실제 인덱스·팔레트와 같음을 확인했습니다. `production_input_check.json`에서 같은 최종 설치 좌표로 NullCache 준비9개가 모두 비지 않으며 기존 ID 원본과 일치합니다.
