## 원본·그림·설치

- 원본 계약은 `test_current/parts/effect_21819_19584/candidate_21819_contract.json`에서 실제 해시·인덱스·전체16색으로 대응했습니다. 실제 흰색/연보라/어두운 보라3팔레트는 각기 생성한 칸의 색을 사용했고, 다른 팔레트 그림을 재색칠하지 않았습니다.
- 원형 띠는 작은16×16 원과 큰32×32 원의 가운데 줄에서 양쪽2픽셀씩 남는 원본 폭을 참조해 따로 생성했습니다. 작은 원은 지름 대비 넓고 큰 원은 상대적으로 얇은 같은2픽셀 띠입니다.
- 대각선은 원래 연속/끊김 구분과 실제색을 유지하는 별도 생성 칸을 사용했습니다. 가로줄은 원래32×2 지원 상자에 배치했습니다. 가는 원/선으로 미화하려고 원본 면을 지우지 않았습니다.
- 원천은 `generated_lines_selected.png`, `generated_rings_selected.png`이며 각 원본/생성 상자는 `provenance.json`에 있습니다. 생성 알파 그대로 사용했고 원본 RGB/알파 전사나 강한 알파 문턱 처리는 하지 않았습니다. 경계 상자를 찾을 때만8을 사용했습니다.
- 설치 입력 `install_contract.json`, 원본 `native_atlas.png`(192×128), 후보 `candidate_atlas.png`(정확한4배768×512)입니다. 원본 `spec.source_x/source_y`와 최종 `atlas_box`를 분리했습니다.
- `source_input_check.json`에서 최종 설치13사각형의 불투명 RGB·알파가 실제 인덱스/팔레트와 동일합니다. 같은 최종 좌표로 NullCache 준비13개가 모두 비지 않으며 기존 ID의 원본 해시·인덱스가 같습니다.

- 생성 도구에서 여러 대안이 나왔습니다. 둥근 단추처럼 선/띠가 두꺼워지거나 바깥 안개가 보이는 대안은 설치 입력으로 선택하지 않았습니다. 최종은 대각선 원천과 별도 원3개 원천입니다.

- 라이브 메타·DB·공유 코드·코어·EXE·배포·푸시는 건드리지 않았습니다.
