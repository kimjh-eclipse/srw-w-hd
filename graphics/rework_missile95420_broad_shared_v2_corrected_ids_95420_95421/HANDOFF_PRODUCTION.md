# 바인딩 번호만 정정한 복제 패킷

기존 missile95420_broad_shared_v2의 bindings95419/95420은 배열 인덱스를 표시 ID로 잘못 기록하여 철회됐습니다. 이 새 폴더는 정확한 표시 ID95420/95421과 현재 prior spec SHA로 고쳤습니다. 표시 ID는1-based이며 배열은 ID-1입니다.

원본 hash/index_hash/index_pixels/full16palette를 각 live spec과 모두 대조했고 native 참조 RGBA도 각 사각형과 정확히 같았습니다. 기존 후보·생성·원본 파일은 변형 없이 복사했으며 candidate RGBA/그림 SHA 불변입니다. 메타만 정정한 것으로 새 그림 수는0입니다. 이전 파일은 덮지 않았습니다.

부모95420의32×32와 자식95421의16×16은 같은 새 master를 공유합니다. 위쪽 사선 폭을 넓힌 그림 후보의 실제 형태·색·폭 검사는 여전히 Claude 대기입니다. 이 메타 대조를 그림 합격 또는 HD 재생 합격으로 표시하지 않습니다. 중앙 파일 변경은 하지 않았습니다.
