# 저스티스 두 자세 12종 미검증 후보

- 기존 +400 재제작 후보 10종과 실제 +550의 추가 2종을 한 아틀라스에 포장했습니다. 전체 12종 중 완전 미연결은 +550의 1종뿐이고 나머지 11종은 기존 indexed 다른 색 그림 교체입니다.
- 모든 셀의 HD/native RGBA는 포장 전후 불변입니다. packing_rgba_preservation.json에 SHA12개 보존. 기존 +400 내부 원본 교차 2쌍은 같은 생성 HD가 정확하게 공유됩니다. 추가 +550 2종은 기존10종 및 상호 원본 교차가 없습니다.
- +550 OAM0은 IMG8086 (80,16) 32×16, OAM1은 IMG8113 (88,16) 32×16 원본 인덱스 bytes 일치입니다. palette0 실제 사용색은 source 계약에 보존; ROM 팔레트 후보도 함께 보존했습니다.
- +550 실제 전체18 OAM 중 이전10종과 기존 exact 6종은 의존 유지, 새 그림은2종만 제작했습니다. +400 전체18 OAM 의존은 원래 패킷에 보존했습니다.
- imagegen 내장 도구로 생성했고 원본 알파/RGB를 찍지 않았습니다. 첫 도트형 생성은 보류하고 같은 배치의 고해상도 재작화 최종본을 사용했습니다. 생성 원본 parts_generated.png는 justice_fatum550_missing에 있습니다.
- 위험: 추가2종은 작고 뒤틀린 장갑 연결면이라 모델이 금속 패널/홈을 구체화했습니다. 기존10종과의 표면 분할·명암 연속성 및 실제 가림은 Claude가 판단해야 합니다. 공식 audit/실제 HD 재생은 하지 않았습니다.
- Claude 상태: source_mechanical_fixed_48_214_400/source_pose.state +0와 source_mechanical_fixed_48_214_550/source_pose.state +0. 각각 actual 메뉴400/550입니다. 원래 두 패킷 native 전체 조립과 계약 참고.
- 라이브/DB/코어는 쓰지 않았습니다. root 직렬 연결 대기입니다.
