# IMG21080 남은 10계약: 원본/팔레트 확정, 해당 형태 재생 미관측

## 상태를 정확히 구분
원본계약과실제팔레트는확정됐지만이10개RGB계약을실제재생에서관측한것은아닙니다. 9개는미관측index형태이고1개는이미관측한형태의미관측다른bank계약입니다. 전부Claude확인대기입니다. actual_observed=False,fixture=None,slot=None이며관측된binding0행을만들어내지않았습니다.

## 제작 가능성/그림
PLT21079 bank0/1의16값전체가실제cached팔레트와각각같은것이이미확정됐고,동일IMG21080의남은사각형이므로색추정없이source index+그bank팔레트로CRC/계약을계산할수있습니다. 각RGB/indexCRC는누락큐와정확히일치합니다.
이미새로생성한동일효과전체시트2벌에이10개영역이모두그려져있어같은그림을그대로잘랐습니다. 다른기체그림리컬러/원본RGB·알파스탬프가아닙니다. 이번추가새그림생성0회,기존전체시트와후보합본바이트완전히같음. 단색8×16/16×16과작은15/26pixel점조각도포함했습니다.
전체10개에서후보alpha.max는254~255,빈그림/alpha.max<16인경우는없었습니다. 이는설치입력포장확인일뿐형태/화질/실재생QA판정이아닙니다.

## 최종 입력
- candidate_atlas.png:기존1024×768합본과바이트동일.
- native_atlas.png:기존256×192원본합본과동일.
- install_contract.json:추가10개만. 합본atlas_box1배좌표/실제확정팔레트/원본index/CRC/sourcebox/실재생미관측표시.
- mechanical_input_check.json:빈/nearalpha부재,현재activeRGB/runtimeindexed연결0,원본CRC정합과복사파일해시.
