# 본타 그레네이드 자세의 몸체 4종

- unit266 본타군 무장1100, source_mechanical_266_1100/source_pose.state 로드 후1회run(계약offset0). 원본unit identity는 제작담당 자료로 확인. 원본7OAM 중4종 신규.
- 총 그림이 아니라 올리브 장비/주황 의상/얇은 조각입니다. 한 생성 호출에서 3×2 배치로 그려 생성 자체 RGBA만 사용하고, 각 원본 bbox는 위치/크기 맞춤에만 사용했습니다.
- ROM13893/13894 rawbytes 동일 증거와 actual palette/좌표는 pose_contract와 rom_indices_identity. 기존3OAM 보존.
- Claude 우선: 큰 조각에 버클/손 모양이 추가 발명됐는지, 장비-몸체 접합/얇은조각 곡률, cap이나절단선,색단계와부드러운선굵기. 생성본 가장자리의 낮은 알파 빨강/자홍빛 프린지가 보이면 원본 쌍으로 확인 필요. 제작 원출력은 그대로 남겼습니다.
- 입력계약/크기/알파 생산 검사만 수행. 독립 그림·색·실제 재생 판정은 대기.
