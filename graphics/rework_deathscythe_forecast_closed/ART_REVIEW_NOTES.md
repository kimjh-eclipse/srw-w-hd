# 데스사이즈 닫힌 날개·무장 보유 자세 제작 인계

## 범위
duo_map_forecast.state +0의 실제 기체/무장 17 OAM, 실제 RGB 기준14종 전체를 새로 그렸습니다. 이전 normal20/next14와 actual RGB 중복은 없습니다. 날개·몸체 일부는 좌우 OAM이 같은 그림을 뒤집어 쓰므로 3 OAM은 같은 후보를 재사용합니다. 이 자세는 전투 예측의 기체이며, 공격 애니메이션 전체 완료로 세지 않습니다.

- candidate_pose_for_claude.png: 동일 실제 순서의 후보 조립 파일. QA 판정 이미지가 아닙니다.

## 계약 확보 방식
기본DLL retro_srw_copy_cached_obj + core.obj(rendered OAM)만 사용했습니다. MMU decode를 쓰지 않았습니다. 선택17 OAM 모두 actual hash와 cache hash 일치·크기 일치. unique14개는 각 source IMG 원본 인덱스 사각형과 바이트 일치.
IMG1164의 연속 부분을 같은 좌표로 그린 뒤 겹치는 사각형을 잘랐습니다. 머리/무장/손4개는 아래 별도영역에 배치했습니다. actual palette6의 색 구성이므로 앞서 palette0 그림을 재색칠해 대체하지 않았습니다. 모든 후보는 새그림이고 원본 RGB/알파 찍기나 원본 확대 결과가 아닙니다.

## Claude가 확인할 위치 / 위험
- fixture: test_current/combat/duo_map_forecast.state, offset0(load 후 run1회).
- 전투 예측의 오른쪽 유닛, 닫힌 날개·상체·머리·낫 손잡이·발까지 확인.
- 작은 원본 조각과 상단에서 잘린 날개 끝이 제대로 원래 위치로 이어지는지, 생성기가 붙인 단면 검은선이 있는지 확인해야 합니다.

- 후보 그림은 직접 생성된 연속 시트를 전체비율로4배 축소했으므로 각 세부 형상의 위치/폭이 원본과 다를 수 있습니다. 이음매와 실루엣 검토가 필요합니다.
- 미세한 투명 경계와 배경 잔여는 아직 검증하지 않았습니다. 키색 일괄 삭제나 원본 알파 마스크 복사는 하지 않았습니다.
- QA·독립 시각판정·HD 실제재생은 수행하지 않았습니다. live/library/DB/코어/공유코드는 바꾸지 않았습니다.
