# 샌드록 +270 재제작 6종 보류

- 실제 cachedOBJ 계약과 원본 팔레트/ROM bytes는 확보했지만 그림은 설치 가능한 후보가 아닙니다. installation_map은 만들지 않았으며 라이브에 연결하지 마십시오.
- 신규 미연결 6종이 아니라 전부 기존 indexed 그림이 있는 actual palette 재제작 6종입니다. 첫/두번째 생성 모두 왼쪽 두 연결편을 부풀린 장갑/손 형태로 해석했고 넓은 후광도 남겼습니다.
- 원본 실루엣을 찍어 덮거나 팔레트 재색칠로 수치만 맞추지 않았습니다. 실패 생성 원본을 별도 보존했습니다. 정확한 간결한 원본 지지영역으로 재생성이 필요합니다.
- 마지막 작은 17texel은 ROM 첫 byte일치가 IMG1180이지만 단일 소유 확정은 아닙니다. actual raw/index/palette/size는 확정이며 source resource를 고유 소유자로 단정하지 마십시오.
- 공식 audit/실제 HD 재생은 하지 않았고 core/live/library/DB를 변경하지 않았습니다. 보류는 제작상 명백한 오해에 대한 판단이며 Claude QA 통과/실패 판정을 대신하지 않습니다.
