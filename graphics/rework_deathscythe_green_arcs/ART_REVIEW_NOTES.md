# 데스사이즈 녹색 큰 궤적8 + 가는 궤적2 제작 인계

## 범위
IMG7084의 서로 다른 실제 팔레트2구성 × 형태4개 =8종, IMG7085의 가는 궤적2종 =10종 후보를 제작했습니다. 실제 큰 궤적을2번 각각 새로 그리고 가는 궤적을1번 새로 그렸습니다. 기존 그림 리컬러나 원본 RGB/알파 찍기는 하지 않았습니다.

## 설치 입력
- candidate_atlas.png:768×640 (1배192×160의4배)
- install_contract.json:10개. atlas_box는 합친 후보의1배좌표. group_atlas_box는 개별 새그림의 원래 배치.
- source_contract.json: 합치기 전 실제 원본 계약.
- img7084_frame30_candidate.png / img7084_frame60_candidate.png / img7085_frame30_candidate.png:각각 독립 새그림.
- 각 *_generated.png와provenance.json:생성 원본/출처.
- 각 *_native.png / *_reference.png:실제 캐시 원본과 제작 참조.
- mechanical_input_check.json:10개 원본index 바이트/실제hash/캐시크기 정합 및 파일크기.

## 효과 분류
정확 actual RGB/palette의 static/effect 후보입니다. 금속 낫 기계파츠와 구분해야 합니다. 각 팔레트별 별도 그림/해시를 사용하며 runtime 팔레트 재색칠용 다른 기체 그림을 재사용하지 않습니다.
IMG7084는 packed sheet의 조각이므로 연속 시트에서 원래 사각형을 잘랐고, 절단면에 검은 테두리를 넣지 않도록 지시했습니다. 큰 단색 영역은 빔 내부에 이어지는 면이므로 그림 전체 객체로 자동완성하지 않았습니다.

## Claude 확인 장면과 알려진 위험
- fixture:test_current/combat/duo_map_attack.state
- +30:IMG7084 첫색4종,IMG7085 가는궤적2종(일부OAM반복).
- +60:IMG7084 둘째색4종(일부OAM반복). load후 offset+1 run.
- 큰 궤적 조각의 직선/곡선 경계가 서로 이어지는지, 새그림 선폭과 내부 그라디언트가 실제 원본과 맞는지 확인 필요.
- 큰 조각의 상단/우측/하단 일부가 투명하지 않고 사각형 끝까지 채워지는 것은 원본 의도입니다. 이를 배경 잔여로 오해해 삭제하면 빔이 끊깁니다.
- 가는 궤적은 원본보다 굵거나 어두운 중심선/옅은노란 경계가 추가됐을 수 있습니다. 실제 작은 크기로 볼 때 색/선폭/알파가 맞는지 Claude 확인 대상입니다.
- 생성 결과의 외곽 반투명 점과 미세한 색띠는 아직 검증하지 않았습니다. 키색 일괄 삭제·원본 알파 마스크 복사는 하지 않았습니다.
- QA·독립 시각판정·HD 실제 재생은 수행하지 않았습니다. live/DB/library/코어/공유코드를 수정하지 않았습니다.
