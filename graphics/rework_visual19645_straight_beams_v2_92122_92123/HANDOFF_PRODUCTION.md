# 19645 곧은 대각 빔 두 개 새 교정 후보

## 최신 실제 지적 반영
Claude 지침4에서92123/92122가 원본의 곧은 대각선 대신 S자로 휘었다고 판정했습니다. 이번 새 그림은 약34도의 곧은 축과 매끄러운 직선 경계로 제작했습니다. 원본 픽셀 계단을 그대로 확대하지 않고 연속 색면으로 그렸습니다.

실제92123은 청회색에서 보랏빛 파랑으로 이어지며 아래쪽이 대체로2텍셀,위쪽이1텍셀입니다.92122는 연한 민트색과 청회색 가장자리이며 중앙이 약3텍셀,양끝은1~2텍셀입니다. 곧은 중심축을 유지하면서 이 폭 변화도 새 그림에 반영하도록 요청했습니다. 정상92121은 수정 대상에서 제외했고 작업 시작 메타데이터·그림 지문을 preserved_92121.json에 보존했습니다.

후속 출력에 반투명 광륜이 생긴 것은 최종 후보로 사용하지 않았습니다. 알파 문턱으로 지워 우회하지 않고 원본 참조에서 다시 생성한 generated_selected.png가 최종입니다. generated_gray.png도 이 최종 자체 RGBA를 중성 회색에 합성한 것입니다.

## 새 패킷
- candidate_packet.json에 최종 계약·4배RGBA 그림·1배 원본·생성 원천 네 파일 SHA와 두 바인딩의 작업 시작 spec SHA를 넣었습니다.
- 시작 상태는 prior_binding_spec.json / prior_binding_spec_sha256.json입니다. 현재 spec이 이 지문과 달라졌다면 덮어쓰지 말아 주세요.
- install_contract.json / candidate_atlas.png / native_atlas.png / generated_selected.png는 새 폴더에 만든 파일입니다. 이전 설치 패킷은 변경하지 않았습니다.
- 원천은 test_current/parts/effect_19645_22378_next/observed_contract.json입니다. 두 원본은 unit333/diagnostic_preview/mechanical_cutin_168.state 상대34프레임의 OAM11/OAM9입니다. 실제 raw/index 해시·인덱스·palette_15bit 전체16색을 보존했습니다.
- 원본 좌표[224,16]과[208,32]는 후보 atlas_box[0,0,16,16]과[24,0,32,32]와 구분했습니다. 원천의 미확정 resource 값은 추정 번호로 바꾸지 않았습니다.
- 원본 RGB·알파를 전사하거나 생성 알파를 문턱으로 지우지 않았습니다. 각 자체 생성 그림을 원래 가시 경계 상자에 배치했으며 서로 다른 단계의 그림을 재색칠해 채우지 않았습니다.

## 확인 대기
연결·굽기·검사·캐시·중앙 목록 갱신은 Claude 담당이며 이번 후보에서 실행하지 않았습니다. source_candidate_pair.png와 실제 원천에서 곧은 축·실제 폭 변화·양끝 절단면·청회색/민트색 비율을 확인해 주세요. 현재는 새 그림과 계약을 넘기는 단계이며 시각 합격이나 실제 재생 정상 판정이 아닙니다.
