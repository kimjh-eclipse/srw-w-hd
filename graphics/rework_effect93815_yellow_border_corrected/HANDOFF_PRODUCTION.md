# 93815 노란 경계 자체 새 그림 후보

- Claude의 실제 시각 지적대로 기존 그림의 경계가 거의 흰색으로 빠져 있었습니다. 원본은 불투명258픽셀 중 노랑85픽셀, 금색3픽셀, 나머지170픽셀은 따뜻한 흰색입니다. 노랑이 단순 희미한 광선이 아닌 실제 채워진 면이라는 점을 확인했습니다.
- 기존 전체 형태/연결을 참조해 생생한 노란 경계 면을 갖도록 자체 새 그림을 생성했습니다. 원본 RGB/알파 전사나 출력 색 재매핑은 하지 않았습니다.
- 최종 `install_contract.json`은 **93815 하나만**입니다. `candidate_atlas.png`(128×64), `native_atlas.png`(32×16)입니다. 기존 다른 꼬리93813/93814는 변경하지 않으며 지문을 `preserved_external_tails.json`에 남겼습니다.
- 최종 사전 기하검사 IoU .744, 미칠한 영역.019, 바깥.001, 경고 없음입니다. NullCache 준비 결과 비어 있지 않으며 실제 raw/fullpalette 계약을 유지했습니다.
- `source_current_pair.png`는 원본/기존 그림, `source_candidate_pair.png`는 원본/새 후보입니다. 노랑 면은 기존보다 뚜렷해졌으나 실제 원본 대비 경계 두께/노랑 비율과 주변 꼬리와의 연결은 Claude 수동 확인이 필요합니다. 기존 형태를 따르므로 계단형 꺾임이 남는 부분이 있습니다. 이를 전체 형태 재제작 완료로 주장하지 않습니다.
- 공식 QA/실재생 완료는 아닙니다. 라이브/DB/공유 코드 변경 없음이며 최종 SHA와 실제 프레임은 별도 JSON에 남겼습니다.
