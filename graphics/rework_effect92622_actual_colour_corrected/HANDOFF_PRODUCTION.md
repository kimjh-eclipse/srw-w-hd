# 92622 빔 실제 색 자체 새 그림 후보

- 기존 연속 빔에는 원본에 없는 어두운 파랑이 들어갔습니다. 원본의 가장 어두운 파랑도 RGB(0,115,255)이고 그 위에 밝은 파랑(0,164,255), 청록(0,230,255), 흰색/옅은 청록을 사용합니다. 실제 색 결함으로 판단하고 새 그림을 제작했습니다.
- 기존 연속 윤곽을 유지하며 어두운 남색을 제거하고 실제 밝은 청록/하늘파랑 경계, 위·왼쪽 중심의 흰색과 옅은 청록이 남도록 생성했습니다. 검사 통과를 위한 색 재매핑/원본 RGB 전사는 하지 않았습니다.
- 최종 `install_contract.json`은 **92622 하나만**입니다. `candidate_atlas.png`(128×128), `native_atlas.png`(32×32)이며 같은 묶음의 다른4개는 그대로 보존합니다(`preserved_normals.json`).
- 실제 인덱스·전체16색 계약 일치, 최종 사전 기하검사 IoU .778/미칠한 영역0/바깥0/경고 없음, NullCache 준비 비어 있지 않음을 기록했습니다. 생산 확인이며 공식 색/형태 판정은 아닙니다.
- `source_current_pair.png`의 어두운 기존 경계와 `source_candidate_pair.png`의 새 밝은 경계를 비교할 수 있습니다. 새 그림의 흰 중심·청록/파랑 비율이 원본과 정확히 일치하는지, 빔의 실제 폭과 원래 위·왼쪽 치우친 밝은 부분은 Claude 수동 확인 대기입니다.
- 실제 상태/프레임과 최종 파일 SHA는 별도 JSON입니다. 라이브/DB/공유 코드 변경 없음입니다.
