# 94340 실제 흰 띠 폭 교정 새 후보

## 지적과 수정
Claude의 최신 지침4에서94340의 왼쪽 아래 넓은 흰 띠가 얇아졌다고 판정했습니다. 실제 원본32×8의 아래행은 왼쪽10칸이 순수 흰색255/255/255, 다음11칸이 연청록189/255/255, 나머지가 청록90/255/255입니다. 이전 제작에서 흰 띠를 빼라고 요청한 것이 잘못이었습니다.

이번 새 그림은 왼쪽 아래의 흰색을 가는 중심선이 아닌 채워진 넓은 띠로 포함했습니다. 하단 띠는 수평으로 유지하고 가운데 연청록·오른쪽 청록으로 이어지며, 윗부분만 실제처럼 낮아집니다.94330과 다른 정상 그림은 교체 대상에 포함하지 않았습니다.

- candidate_packet.json에 최종 계약·4배RGBA 그림·1배 원본·생성 원천 네 파일 SHA와 작업 시작 당시94340 spec SHA를 넣었습니다.

- install_contract.json / candidate_atlas.png / native_atlas.png / generated_selected.png는 이 폴더에 새로 만든 파일이며 이전 설치 패킷은 바꾸지 않았습니다.
- 원천은 test_current/parts/retained_fx_round2/art_21683/source_contract.json의 같은 raw/index 해시와 실제16색 행입니다. palette_15bit와 실제 원본 인덱스를 계약에 보존했습니다. resource는 원천의 미확정 값을 유지하고 source_x/source_y[32,48]와 새 atlas_box[0,0,32,8]을 구분했습니다.
- 원본 RGB나 알파를 후보로 전사하거나 생성 알파를 문턱으로 지우지 않았습니다. 자체 생성 그림을 원래 가시 경계 상자에 배치했습니다.
