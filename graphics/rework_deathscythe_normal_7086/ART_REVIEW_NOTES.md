# 데스사이즈 일반 전투 한 자세: 제작 후보 인계

## 상태
그림 제작과 연결 입력만 준비했습니다. QA·독립 시각 판정·HD 실제 재생 검증은 하지 않았습니다. 라이브 라이브러리·DB·런타임은 수정하지 않았습니다.

## 최종 입력
- candidate_atlas.png: 1440×1152, install_contract.json의 atlas_box는 1배 좌표이며 그림은 4배.
- candidate_continuous_source.png: 1024×384, 실제 IMG 7086의 256×96 시트 전체에 대응하는 연속 그림. 각 파츠는 이 그림에서 잘랐으므로 겹치는 원본 좌표의 픽셀은 동일합니다.
- generated_continuous.png 및 provenance.json: 실제 생성 원본과 출처.
- install_contract.json: 20개 실제 OAM의 indices/hash/palette/바인딩/반전/위치/소스 사각형.
- candidate_pose_for_claude.png, native_pose.png, pure_native_context.png: 조립 검토용. 후보 조립은 판정 근거가 아닌 제작 산출물입니다.

## 원본 입력 정정
최초 MMU decode 입력은 보류하고 별도 진단 DLL의 retro_srw_copy_cached_obj + core.obj(rendered OAM)로 같은 실제 시점을 다시 추출했습니다. 20개 모두 캐시 hash == core.parts 실제 hash, 크기 일치, indices/16색 팔레트도 최초 추출과 일치합니다. cached120/all_oam.json과 cached_mechanical_check.json 참조. IMG 7086의 각 source_box 인덱스도 실제 캐시 바이트와 일치합니다. 에너지 날 2종은 본체와 다른 실제 팔레트를 쓰므로 각 계약의 actual_palette를 보존해야 합니다.

## 변경 범위
기존 7108 대형 컷인 3개와 별개인 일반 공격 자세 20개 전부. 원본과 같은 머리·몸통·팔·다리·날개·낫 축·녹색 날의 한 벌입니다. 기존 잘못된 색 팔레트 재사용 연결 대신 실제 RGB 계약으로 별도 후보를 연결하도록 인계합니다. 원본 RGB 또는 알파를 후보에 찍지 않았고, 원본을 확대하여 후보로 쓰지 않았습니다.

## Claude 검토 대상
- state: test_current/combat/duo_map_attack.state
- 제작 추출 offset: 120 (load 후 run 121회). 120 전후 자세 및 낫/날개 이동 중도 확인 필요.
- 모든 조각의 실제 색, 특히 노란 V/초록 눈/붉은 날개 끝.
- 연속 시트 생성물이 원본 위치를 미세하게 바꿀 수 있으므로 팔·몸통·날개 접합과 얇은 축 위치를 확인해야 합니다.
- 원본의 작은 조각에 생성기가 기계 디테일을 추가했을 가능성이 있습니다. 특히 둥근 연결부, 평판, 조그만 삼각형은 역할을 임의로 확정하지 않았습니다.
- 그림의 투명 테두리와 칼날 외곽에 생성된 반투명 잔여가 있을 수 있습니다. 별도 키색 삭제·원본 알파 복사는 하지 않았습니다.
- candidate_atlas_v1.png / generated_v1.png는 개별 셀 첫 시도이며 설치 금지. 후보 접합을 독립 그림으로 만들지 않으려고 연속 시트로 다시 제작했습니다.
- source7086_reference.png는 팔레트 하나만 적용한 초기 임시 자료라 실제 색 참조로 사용 금지. 실제 색 참조는 continuous_source_reference.png, all20_reference.png, cached120/ 입니다.
