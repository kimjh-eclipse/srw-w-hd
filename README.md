# 슈퍼로봇대전 W HD

2026-11-08 표시·진동 수정: 서브 화면에도 원본 OAM, 팔레트, 우선순위와 기체 파츠를 전달합니다. 메인 화면에만 적용되던 교체 경로를 양쪽으로 연결했으며, 미등록 서브 파츠도 기존 타일 조합 경로로 수집합니다. 실제 저장 상태의 발호크·발스토크 능력 화면과 전투 확인 화면을 검사했습니다. 선택 메뉴의 검은 글자 배경은 버튼의 초록색 그라데이션으로 복원하며, 전투 확인·무기·지도 명령 14개 선택 상태를 검사했습니다.

진동은 사용 중인 OBJ 팔레트 16개를 검사하며, 빔 감지는 HD 표시 여부와 무관하게 원본 OAM을 읽습니다. 빨간 빔과 얇은 흰색 빔을 추가했고, 빔 펄스는 110ms 동안 저주파 모터 강도를 교대로 바꿉니다. 기존 전투와 에이드·본타군 데모에서 HD 켜짐/꺼짐 결과를 비교했습니다. 실제 모터의 체감 강도 및 플라즈마 계열 모든 기술은 아직 검증하지 않았습니다.

사용자가 보고한 데스사이즈·샌드록 공격 파츠와 듀오·카토르 컷인의 누락은 미해결 항목입니다. 서브 화면 경로 수정이 이들의 모든 공격 자료가 완성됐다는 뜻은 아닙니다.

공개 저장소에는 롬·세이브·인증 정보를 포함하지 않습니다. 큰 이미지와 검사 자료를 받으려면 Git LFS가 필요합니다. 업로드 범위와 현재 알려진 문제는 [REPOSITORY.md](REPOSITORY.md)에 기록했습니다.

현재 내부 HD 해상도는 양쪽 화면 모두 768~960 기준입니다. 화면 크기와 부하에 따라 이 범위에서 조정하며, 전체 화면에서도 상한은 960입니다. 등록된 실행용 그림 1,009개를 표시 배율에 맞춰 줄였고, 초상화 548개와 메뉴 캐시를 다시 준비했습니다. 큰 지도·파츠 시트는 여러 화면이나 파츠가 묶인 크기이므로 실제 표시 배율을 기준으로 제한합니다.

실행은 `emulator/HD_게임실행.cmd`입니다. 기존 실행 창이 열려 있다면 게임을 다시 열어 새 코어와 그림을 읽습니다. 한글 1.0.8 기준 ROM 한 개를 유지하며, 음성 추가는 사용자 요청에 따라 중단했습니다. ROM에 HD 그림을 넣는 방식이 아니라 수정한 DeSmuME가 원래 파츠·팔레트·레이어를 대조해 HD 그림을 합성합니다. 일반 DS 에뮬레이터와 실기에는 이 HD 교체가 적용되지 않습니다.

## 현재 적용

기체는 원래 파츠 배치, 회전, 반전과 겹침 순서를 유지합니다. 기존 기본 형태 269개와 보조 묶음 외에 공격·변형·피격·파괴 자료를 추가했습니다. 실제로 관측한 639개 파츠 무늬는 13개 AI 시트로 보완했고, 전체 검토 대상의 추가 기계 자료는 136개 시트, 부분 팔레트 자료는 8개 시트로 구성했습니다. 생성과 등록의 실제 완료 수는 `graphics/animation_parts/completion_status.json`에서 확인합니다. 숫자는 서로 다른 기체 수나 게임 전체 완성률이 아닙니다.

여러 IMG에 걸친 실제 하드웨어 파츠는 원본의 8×8 타일 바이트를 직접 대조해 HD 조각을 조합합니다. 색 인덱스와 원본 투명 영역을 유지하며, 완성된 파츠는 CRC와 별도의 재질 식별값을 모두 확인한 뒤 표시합니다. 준비·퇴거·불일치 중에는 원본 표시를 유지합니다. 부분 팔레트의 추정 색상은 출처를 기록하고 실행 시 실제 게임 팔레트를 적용합니다. 승인된 카즈마 기체 얼굴과 초기 5,263개 연결 번호를 보존합니다. 충돌한 6개 인덱스 키는 자동 교체에서 제외합니다.

초상화 548개 리소스와 가우롱의 두 컷인을 AI로 다시 그려 연결했습니다. 초상화 수에는 표정·복장·색상 변형과 통신 장치가 포함되며, 서로 다른 인물 548명이라는 뜻은 아닙니다. 얼굴 원본을 두 단계로 대조하고 HUD·대사와 원래 투명 영역을 보호합니다. 배경은 실제 데모에서 관측한 도시·필드·우주·갑판·숲과 타워 전경에 HD 그림을 연결했습니다. 스크롤과 원래 레이어 마스크를 유지하고, 특수 색상 효과가 일치하지 않을 때는 원본으로 표시합니다. 일치하는 12픽셀 한글 글자는 원래 좌표와 줄바꿈을 유지하며 맑은 고딕으로 다시 표시합니다. 위·아래 화면과 이전 화자의 회색 대사에 적용합니다. 8픽셀 폭 숫자·영문·기호와 8×8 HP/EN 숫자도 같은 글꼴로 표시합니다. `1/1`, `0/0`, `5000/5000`, `170/170`, `±0%`와 작은 숫자 0~9, `/ ? + - ±`를 검사했습니다. 다른 그림에 포함된 문구는 원본으로 남을 수 있습니다. 글자 일치 여부는 원본 비트맵과 정확히 대조하며, 부분 출력·가림·미확인 글자를 추측하지 않습니다.

## 속도와 조작

파츠 그림 준비와 화면 합성을 각각 별도 프로세스에서 수행합니다. 원본 파츠가 사라지는 시점은 HD 준비 완료와 연결했습니다. 필요한 아틀라스만 읽고 미리 준비한 파츠·팔레트·손실 없는 디스크 캐시를 재사용합니다. 캐시 확인 시 사용하지 않는 모든 HD 파일을 다시 읽지 않습니다. 초상화는 최종 표시 텍스처를 사전 준비하고, 실행 중 비동기로 읽습니다. 원본 타일과 팔레트가 그대로면 해석 결과를 재사용하며, 양쪽 고해상도 화면 결과를 공유 메모리에 직접 기록합니다. 아래 화면의 초상화와 글꼴 처리도 합성 프로세스에서 수행합니다. 글꼴과 대사 배치는 캐시하고 바뀐 배경과 글자 영역만 갱신합니다. 게임 진행·소리는 모든 프레임 처리하고 원본 화면 계산은 HD 표시 주기에 맞춥니다. 동일한 저장 전투를 창 활성 상태로 다시 재생해 초기 로딩을 제외한 같은 프레임을 비교했습니다. 지도 복귀 합성은 106.8→30.4ms, 최악 화면 갱신 간격은 111.9→38.3ms, 33ms 초과 갱신 간격은 12→3회였습니다. 일반 실행 두 차례의 실제 화면 평균은 59.2~59.6fps, 1초 단위 최저는 54.0~54.9fps입니다. 평균만으로 고정 60fps를 달성했다고 표시하지 않습니다. 전투 뒤 지도·메뉴 첫 표시의 지연과 일부 프레임 누락은 남아 있으며 전체 캠페인 검증도 미완료입니다. 비교 범위와 원자료는 `test_current/performance/hitch_comparison.json`에 있습니다.

지도 인덱스를 메모리에 유지하고, 지도 PNG 해독과 전체 월드 확대를 별도 작업으로 준비합니다. 준비 중에는 원본 지형을 잠깐 유지하며, 준비 완료 후 동일한 HD 월드를 표시합니다. 아이콘 팔레트 변환은 사전 준비하고 바뀐 영역만 다시 검색합니다. 글자 모양·공통 UI·승인된 소수 파츠의 표시 크기를 미리 준비하며, 글자 배경 복구와 두 화면의 GPU 전송에서 동기 대기를 줄였습니다. 게임 실행 프로세스에도 1ms 타이머 정밀도를 요청합니다. ‘60프레임 우선’을 켜면 768 기준으로 시작하고 여유가 충분할 때만 해상도를 올립니다.

화면 더블클릭으로 전체 화면을 켜고 끕니다. 메인 크게·같은 크기와 가로·세로의 네 배치, 화면 교환을 지원합니다. 화면 사이 고정 여백을 없앴고 양쪽에 같은 확대 처리를 적용합니다. 창 비율 때문에 생기는 남는 공간은 있을 수 있습니다. 포커스를 잃어도 게임은 계속 진행하고 눌린 입력과 진동만 해제합니다.

설정에서 게임 조작과 빠른 진행·저장·불러오기·일시정지·계속을 키보드와 패드 버튼에 지정합니다. 기본 기능 키는 Tab 누르는 동안 빠른 진행, F5/F8 선택 칸 저장·불러오기, Space 일시정지/계속, Pause 일시정지, F6 계속입니다. 요청 배속은 2/4/8/16배이며 실제 속도는 기기 성능에 따라 달라집니다. 빠른 진행 중 음성과 진동은 잠시 끕니다. 물리 패드 진동은 연결 기기에서 별도 확인이 필요합니다. 패드 검색·입력·진동은 별도 SDL 프로세스에서 처리하며 게임 창에서는 SDL 조이스틱을 초기화하지 않습니다. 패드 프로세스가 종료되거나 응답을 멈추면 눌린 입력을 해제하고 자동으로 다시 시작합니다. 가상 패드 20회 연결·해제, 패드 프로세스 강제 종료·응답 지연, GPU 화면 갱신과 키보드·패드 단축키를 검사했습니다. 검사 당시 연결된 PS4 Controller와 Xbox 360 Controller의 인식도 확인했습니다. 실제 케이블 재연결과 물리 진동 강도는 별도 확인이 필요합니다.

## 검사와 한계

실제 전투 장면, 네 화면 배치·더블클릭 전체 화면·패드 연결 예외·저장/불러오기·빠른 진행 복귀, 원본 대비 파츠와 팔레트, 캐시 퇴거 후 복구를 검사합니다. 초상화는 548개를 세 위치에서 연결 검사한 총 1,644건과 실제 관측 얼굴을 별도로 검사했습니다. 전체 초상화 카탈로그 검사는 원본 이미지로 구성한 화면을 이용하며, 모든 인물이 나오는 실제 전 구간 재생 검사가 아닙니다. 모든 무기·변형·격추·특수 연출의 캠페인 검증은 아직 완료하지 않았습니다. 전체 게임을 완전 HD화했다고 표시하지 않습니다.

검사 결과는 `test_current/parts/`, `test_current/portrait/`, `test_current/gui/`에 있습니다. 생성 프롬프트와 원본 생성 그림의 출처는 각 `graphics/` 하위 자료에 기록했습니다. 원본·기준 한글 ROM·다른 프로젝트 파일은 보존합니다. 유일한 시험 ROM은 `release_battle_v02/SRWW_K_Kazuma_BattleVoice_v02.nds`입니다.

소스는 DeSmuME GPL-2.0-or-later이며 전체 수정 소스는 `emulator/desmume/`, 변경분은 `emulator/hd_core.patch`, 빌드 정보는 `emulator/BUILD.txt`에 있습니다. 이전 음성 실험의 엔진·음원·조사 자료는 보존하지만 현재 기능은 비활성입니다.


## 2026-11-08 공통 합성 수정

반투명 메뉴 배경의 회색 무늬를 글자로 오인해 HD 글자가 깜빡이던 경로를 수정했습니다. 전투 확인·무기 선택 화면을 각각 120프레임 재생해 글자와 선택 상태가 유지되는지 검사했습니다.

컷인 앞뒤 순서에서는 BG가 앞에 있을 때 뒤쪽 기체에 적용할 두 번째 혼합 계수를 반영합니다. 진겟타·고라이온의 실제 데모 저장 장면에서 수정 전후를 확인했고, OBJ/BG 우선순위·혼합 모드·계수 0~16 조합 139,264건과 별도 등록 컷인 세 경로를 검사했습니다. 이 숫자는 모든 캠페인 컷인을 실제로 재생했다는 뜻이 아닙니다. 특수 창·래스터 연출과 전체 캠페인 실재생 검증은 계속 필요합니다.

에이드·포신·본타군을 포함한 공격 팔레트 검사에서는 원본에서 쓰지 않는 색 슬롯을 HD 음영이 선택하지 못하게 했습니다. 추가로 원본 인덱스 해시가 일치한 16,355개 파츠의 재질 번호를 약 1.69 MB 캐시로 준비했습니다. 큰 색 변환에서는 원본 재질 위치와 제한된 밝기 세부를 사용합니다. 원본 파츠의 투명도와 배치는 보존합니다. 일부 생성 그림의 연결선과 미등록 파츠의 원본 표시는 여전히 남을 수 있습니다.

두 창의 설정 저장이 충돌해 UI 갱신이 멈추던 문제도 수정했습니다. 각 저장에 별도 임시 파일을 사용하며, Windows의 짧은 파일 잠금은 제한적으로 다시 시도합니다. 동시 저장 120회를 검사했습니다. 실행 중 등록 캐시와 개인 설정·오류 로그는 이번 소스 변경에 포함하지 않습니다.

검사 자료: `test_current/combat/cutin_composition_audit.json`, `test_current/combat/cutin_blend_verification.json`, `test_current/parts/live_effect_palette_verification.json`, `test_current/font/translucent_text_and_palette_verification.json`.


최신 실제 창 재검사에서 본타군 확대 연출의 잔여 분홍 테두리를 추가로 발견했습니다. 원본 재질에 다른 재질의 밝은 HD 음영이 과하게 더해지지 않도록 재질별 음영을 제한하고, 자동 생성 파츠의 기본 팔레트 표시에도 같은 보정을 적용했습니다. 파츠 위치·원래 알파는 유지합니다. `verify_edge_palette.py`는 실제 세 저장 장면의 알파 일치와 본타군 확대 프레임의 의도하지 않은 분홍 픽셀 제거를 비교합니다. 이 검사는 전체 무장·전체 캠페인 검증을 대신하지 않습니다.
